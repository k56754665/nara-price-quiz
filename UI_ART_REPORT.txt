추가 수정 — 조작부를 게임 안으로 통합
  사용자 피드백에 따라 추측 제출·오류 안내·금액 가감·규격·메뉴를 모두 무대 안으로 옮겼다.
  하단 흰 말풍선 안에 금액 입력과 추측 제출 버튼을 함께 배치했다.
  최신 요청에 따라 추가 금액 패널은 삭제하고 +1000만 옆에 +1억을 기본 버튼 줄에 표시했다.
  규격은 무대 안에서 열리는 패널이며 게임 도구는 왼쪽 위 메뉴로 통합했다.
  외부 웹 헤더·푸터·회색 여백·문서 스크롤을 제거하고 화면 비율에 따른 여백은 커튼 계열의 보라색으로 표시한다.
  메뉴 조작 시 무대가 내부 스크롤되어 이미지 위치가 밀리는 문제는 overflow: clip으로 해결했다.
  라운드 정답 안내도 같은 무대 배경 위 내부 패널에 표시한다. 기존 데이터·채점·진행 함수는 유지했다.

연결한 기존 기능
  상품 사진: q.image.src와 기존 photo(q). 클릭하면 기존 이미지 확대 대화상자를 연다.
  상품명·물품명·업체: q.title, q.specification의 물품명, q.supplier.
  전체 규격·수량·인도조건·부가세·가격 기준 고지: 기존 conditions(q)를 무대 안 '규격 보기' 패널에서 표시.
  라운드: state.index + 1. 전체 문제 수는 접근성 이름으로 유지.
  누적 점수: 기존 totalScore(state.rounds).
  입력 금액: 기존 state.draft, parseGuess, 입력 포맷, 한국어 금액 안내, 브라우저 저장.
  긴 금액 표시: 입력 글자 수에 따라 글자 크기만 조절. 입력값과 허용 범위는 기존과 동일.
  UP/DOWN: 기존 guessHint. 최초 상태에는 정답 방향을 추정하지 않고 '?'를 표시.
  거리 힌트·추측 이력·남은 기회 안내: 기존 retryFeedback(q)를 게임 왼쪽 말풍선에 표시.
  하트: MAX_ATTEMPTS - state.attempts.length. 라운드별 추측 기회이며 별도 전역 목숨 규칙을 추가하지 않았다.
  +1만/+10만/+100만/+1000만/초기화: 기존 add/clear 이벤트.
  +1억: +1000만 다음 기본 버튼으로 표시. 사용자의 요청으로 추가 금액 패널과 그 안의 빼기 버튼 UI는 제거.
  제출·Enter·정답 판정·다음 라운드·재시작·처음 화면·점수 안내: 기존 이벤트와 함수.
  랭킹·데이터 안내·효과음·전체 화면 도구: 게임 왼쪽 위 메뉴에 기존 data-action으로 연결.
  라운드 정답/실패 화면의 기존 내용과 버튼은 유지하고, 무대 배경 위 내부 패널로 표시.

시안 차이와 미검증 부분
  시안의 980점/벤치/라운드/하트는 고정 그림으로 넣지 않았다. 실제 데이터와 진행 상태에 따라 바뀐다.
  시안에는 빠진 제출 버튼·오류 안내·거리 힌트·가감 전체 기능을 제공된 말풍선과 무대 내부 메뉴로 통합했다.
  목재 전면 가로 비율과 관객 반복 배치는 제공된 시트로 시안에 가깝게 맞췄다.
  모바일 세로 화면에서는 같은 에셋으로 패널과 조작부를 재배치한다. 실제 휴대폰 키보드는 미검증.
  Safari/Firefox·실제 터치 기기·실제 오디오 출력·실제 전체 화면 전환은 미검증.
  온라인 랭킹 쓰기·카카오/시스템 공유의 외부 실행·공개 배포는 이번 작업에서 수행하지 않았다.
  이 기능들의 기존 구현과 설정은 유지했지만 이번 실제 외부 동작 검증 완료로 간주하지 않는다.
  메인·결과 화면에 새 시안을 적용하는 작업은 범위 밖이다.
